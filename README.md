This R Shiny called BikeCountsCoV app shows the bike count data from the City of Vancouver 2018 to 2022 automatic counters based on a date range and a set of locations.

 There are three main features of this app:

 - FEATURE 1: Plot showing amount of bikes counted at locations that updates with the date range inputted and locations selected.
 - FEATURE 2: Table showing the amount of bikes counted at locations that updates with the date range inputted and locations selected.
 - FEATURE 3: Tab feature that allows you to select if you want to see the table or the plot.

 You can test out the app for yourself at [link_to_shinyapp.io](https://adress-gif.shinyapps.io/bikecountscov/)
